CONQAPPS GITHUB PAGES YUKLEME

1) Bu ZIP'i bilgisayarında aç.
2) GitHub'da conqapps/conqapps.github.io deposuna gir.
3) Add file > Upload files seç.
4) index.html, style.css, privacy.html ve images klasörünü yükle.
5) Mevcut app-ads.txt dosyasını SILME.
6) Commit changes butonuna bas.
7) Birkaç dakika sonra https://conqapps.github.io/ adresini yenile.

Not: Uygulama/oyun ikonları ve ekran görüntüleri Google Play'deki resmi görsel bağlantılarından yüklenir.
